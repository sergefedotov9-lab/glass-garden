# Круглый квартал

«Круглый квартал» — игра «три в ряд» с градостроительством. Собирайте комбинации из стеклянных шаров, зарабатывайте очки и тратьте их на развитие города: от первого дома и грунтовой дороги до небоскрёбов и широких улиц.

## Скачать для Android

[Скачать последнюю версию для Android](https://github.com/sergefedotov9-lab/glass-garden/releases/latest). APK находится в разделе **Assets**.

[Обсудить игру в Telegram](https://t.me/krugly_kvartal) — обновления, видео и скриншоты городов игроков.

## Как играть

1. Нажмите на два соседних шара или сдвиньте один свайпом. Если в ряд соберутся три или больше одинаковых шара, они разобьются со звоном стекла.
2. Новые шары заполнят поле. Если они сами сложатся в ряд, начнётся каскад с дополнительными очками.
3. Откройте раздел **«Город»**, выберите участок и потратьте заработанные очки на строительство. Бюджет сохраняется между партиями.

## Что есть в Android-версии

- **Карта 6×6.** На 36 участках можно строить дома, парки с фонтанами, школы и клиники.
- **Дома уровней 1–20.** Улучшайте маленький дом поэтапно. Начиная с 17-го уровня ему нужен участок 2×2. Три соседние клетки должны быть свободны, а внутри квадрата не должно быть дорог.
- **Дороги уровней 1–5.** Проложите грунтовку между соседними участками и улучшайте её вплоть до четырёхполосной дороги. По дорогам ездят машины.
- **Городские службы.** Соединяйте жильё со школами и клиниками. Панель города показывает население и долю жителей с доступом к каждой службе.
- **Имя города.** Нажмите на карандаш рядом с названием города, чтобы ввести своё.
- **Обучение и настройки.** После пробного хода можно выбрать один из трёх режимов сложности. В настройках доступны подсказки, темы, фоны и регулировка звука.
- **Эффекты.** При совпадениях разлетаются стеклянные осколки, каскады подсвечивают очки, а строительство сопровождается световым кольцом.

Игра работает без интернета на Android 7.0 и новее. Прогресс хранится на устройстве. При подключении к интернету игра проверяет наличие обновлений в GitHub Releases.

## Веб-версия в этом репозитории

Ветка `main` содержит более раннюю браузерную версию. В ней есть поле «три в ряд», город на 16 участков, строительство зданий и дорог. Расширенная карта и уровни улучшений выше относятся к Android-версии.

## Локальный запуск

Нужен Node.js 24 или новее. Из корня проекта выполните `npm run dev` и откройте адрес, указанный в терминале. Для локального предпросмотра используется временная база SQLite, которая сбрасывается при остановке процесса.

## Развёртывание

Клиент использует `/api/game`. Серверная проверка ходов, строительства и бюджета реализована в `server/worker.js`. Для публикации серверу нужны авторизованные запросы от доверенного хостинга и база Cloudflare D1 с миграцией из `drizzle/`. Команда `npm run build` собирает Worker. Для публикации через Sites укажите ID своего проекта в `.openai/hosting.json`.

GitHub Pages обслуживает статические файлы. Для игры с серверным сохранением используйте хостинг, который обслуживает и интерфейс, и игровой API. Локальный предпросмотр не предназначен для публичного развёртывания.

Личные сохранения игроков в исходники не входят.
